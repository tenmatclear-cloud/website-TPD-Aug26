Uppercase kicker label above a section heading — navy on light, gold on navy.

```jsx
<Eyebrow>Learning objectives</Eyebrow>
<Eyebrow onDark bordered>JC GoAI Project</Eyebrow>
```

`onDark` switches to gold text for navy/hero surfaces. `bordered` wraps it in a hairline pill (used as the hero kicker). Always uppercase, weight 800, letter-spaced. Pair directly above an `<h1>`/`<h2>`.
