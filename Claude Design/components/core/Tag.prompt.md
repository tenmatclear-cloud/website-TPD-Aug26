Small uppercase pill for categories, audiences and article labels; colour is semantic in the brand role map.

```jsx
<Tag tone="programme">Event</Tag>
<Tag tone="schools">News</Tag>
<Tag tone="soft" size="sm">Primary</Tag>
```

Tones: `programme` (orange), `teachers` (green), `schools` (yellow — default, navy text), `navy`, `soft` (light-blue tint), `outline` (hairline). Sizes `sm` / `md`. Always uppercase, weight 800, fully pill-rounded. Keep to one tone per context — don't rainbow a row of tags.
