Large impact number with a caption — built for the signature yellow/navy split stats section.

```jsx
<StatBlock value="255M" label="HKJC Charities Trust funding (HK$)" />
<StatBlock value="3 days" label="Workshop programme" onDark />
```

Navy text by default (sits on the yellow half); pass `onDark` for the white-on-navy half. Numbers use the heaviest weight (900). Keep labels short — one line ideally. Reserve for genuine headline metrics, not decorative stats.
